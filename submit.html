Hosted a cup? The Top->Out mod saved its results on your PC. Drop that file below, check the result and send it. A few minutes later the cup is on the leaderboard.
  • The file is %APPDATA%\Zeepkist\Mods\TopOutTournament\topoutresults_bckp.json (paste that path into the Explorer address bar).
  • Send it right after the cup: the mod replaces the file when your next Top->Out event ends.
  • The file is read here in your browser first. Nothing is uploaded until you press Submit.
